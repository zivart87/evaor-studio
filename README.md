# EvaOr — Particle Studio

Interactive light and particle editor for the EvaOr logo. Built with browser Canvas, with no backend or external runtime dependencies.

## Features

- Six animation models, including a rotating plasma sphere and layered light arcs with contour sparks.
- EvaOr logo preview with animated O, Montserrat weights, O scaling and letter spacing.
- Named variants with a preview gallery, restoreable trash and JSON import/export.
- PNG and browser-supported MP4 export.

Saved variants remain in each visitor's browser; JSON files can be used to transfer or back up settings. Clearing website data removes local saves.

Hosted with GitHub Pages from the main branch root. Montserrat is bundled under the SIL Open Font License; see fonts/OFL-Montserrat.txt.
